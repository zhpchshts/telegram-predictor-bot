# Политика безопасности

«Клевер» работает в production и обрабатывает подписанный Telegram-контекст,
поэтому сообщения об уязвимостях нужно передавать приватно.

## Как сообщить

Используйте **Security → Report a vulnerability** в репозитории GitHub, если
эта возможность доступна. Если приватная форма недоступна, сначала свяжитесь с
владельцем репозитория через его [профиль GitHub](https://github.com/zhpchshts),
не раскрывая технические детали публично, и согласуйте приватный канал.

Не создавайте открытый Issue с:

- токенами бота, Telegram `initData` или launch token;
- содержимым `.env`;
- Telegram API credentials;
- файлами Telethon session;
- персональными данными пользователей;
- инструкцией, позволяющей воспроизвести уязвимость в production.

В приватном сообщении укажите затронутый компонент, влияние, условия
воспроизведения и безопасный минимальный пример. Не изменяйте и не удаляйте
production-данные при проверке.

Поддерживаются исправления для текущей ветки `main`. Публичный SLA ответа пока
не установлен.
