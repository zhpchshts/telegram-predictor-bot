<h1 align="center">Клевер</h1>

<p align="center">
  Telegram-бот и Mini App для конкурсов прогнозов на спортивные и
  киберспортивные турниры в групповых чатах.
</p>

«Клевер» позволяет участникам одного Telegram-чата создавать конкурсы,
прогнозировать результаты матчей и серий, следить за рейтингом и сравнивать
закрытые прогнозы. Основной интерфейс работает внутри Telegram Mini App.

Сейчас доступны готовые шаблоны для:

- Чемпионата мира по футболу 2026;
- The International 2026.

## Возможности

- несколько активных и завершённых конкурсов в одном Telegram-чате;
- прогноз счёта матча или серии с автосохранением до времени начала;
- отдельный прогноз команды, которая пройдёт дальше;
- долгосрочные прогнозы на чемпиона и итоги швейцарского этапа;
- автоматическое начисление баллов и детерминированные тай-брейкеры;
- рейтинг, история закрытых прогнозов и журнал действий;
- публикация прогнозов, результатов и итогов конкурса в Telegram;
- управление супермодераторами на уровне чата.

## Как открыть

1. Добавьте [@ZhpchshtsPredictorBot](https://t.me/ZhpchshtsPredictorBot) в
   групповой Telegram-чат.
2. Отправьте в чате команду `/app`.
3. Нажмите кнопку «Открыть Клевер» и выберите или создайте конкурс.

Контекст конкурса привязан к чату, поэтому полноценное управление через личные
сообщения или отдельный набор команд не предусмотрено.

## Стек и устройство

- Python 3.14, FastAPI и aiogram;
- SQLite;
- HTML, CSS и JavaScript без отдельного frontend build pipeline;
- Docker Compose;
- один процесс приложения запускает API, Telegram polling и фоновые воркеры.

Основные каталоги:

- `app/` — API, бот, бизнес-логика, база данных, начисление баллов и публикации;
- `tma/` — интерфейс Telegram Mini App;
- `tests/` — автоматические тесты;
- `scripts/` — служебные миграции и операции обслуживания.

Подробные продуктовые правила и ограничения для разработки описаны в
[`AGENTS.md`](AGENTS.md), а канонические публичные тексты и визуальные принципы
— в [`docs/branding.md`](docs/branding.md).

## Локальный запуск

Понадобятся Python 3.14 и Telegram-бот, созданный через BotFather.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Заполните как минимум `BOT_TOKEN` и `BOT_USERNAME` в `.env`, затем запустите:

```powershell
python -m app.main
```

Проверка состояния будет доступна по адресу
`http://127.0.0.1:8000/health`. Для запуска Mini App внутри Telegram нужен
публичный HTTPS-адрес в `PUBLIC_BASE_URL`.

Альтернативный запуск через Docker:

```powershell
docker compose up --build
```

## Данные и production

Проект работает в production. База SQLite, Telegram MTProto session и секреты
не должны попадать в Git или диагностические артефакты.

`initialize_database()` создаёт актуальную схему для новой базы, но не является
универсальным механизмом обновления исторических схем. Перед изменением схемы
или логики начисления баллов необходимо проверить совместимость с существующими
конкурсами, матчами, результатами и прогнозами.
