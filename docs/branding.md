# Бренд «Клевер»

Этот файл фиксирует публичные формулировки и ассеты, чтобы Telegram, GitHub и
само приложение описывали продукт одинаково.

## Название и позиционирование

Название: **Клевер**.

Основная формулировка:

> Telegram-бот и Mini App для конкурсов прогнозов на спортивные и
> киберспортивные турниры в групповых чатах.

Не следует называть весь продукт только футбольным: текущие шаблоны включают
Чемпионат мира по футболу 2026 и The International 2026.

## Telegram

Имя бота: `Клевер`.

Короткое описание:

> Конкурсы прогнозов на спорт и киберспорт для Telegram-чатов

Полное описание:

> Клевер помогает проводить конкурсы прогнозов на спортивные и
> киберспортивные турниры в групповых чатах. Добавьте бота в чат и отправьте
> /app, чтобы открыть Mini App.

Команды:

- `/app` — Открыть Клевер для этого чата;
- `/help` — Как открыть приложение.

Аватарка: [`assets/branding/klever-avatar.png`](../assets/branding/klever-avatar.png).
Она сохраняет образ зелёного клевера, а центральный кубок обозначает конкурс и
победу без привязки к конкретному виду спорта. Аватарка Telegram меняется
вручную через BotFather.

## Визуальные принципы

- основной образ — зелёный клевер;
- тёплый золотой используется только как акцент;
- знак должен читаться в маленьком круглом аватаре;
- центральный символ не должен привязывать бренд только к футболу или только к
  киберспорту;
- в изображениях не используются текст, сторонние логотипы и реальные данные
  участников.
